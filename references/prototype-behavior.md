# 交互原型行为

### 交互原型

先为所有可到达页面建立清单，记录：入口、目标、返回目标、滚动容器、固定头/底、弹层、是否仅用于交互。读取 [逐页检查表](page-checks.md)，按实际页面类型执行。

- 同一页面的卡片正文、详情入口和主按钮可能去不同目标，逐一绑定并阻止事件冒泡误跳。不得把所有 CTA 都接到同一个详情页或 toast。
- 已有用户提供的目标页，就接入该页；未提供的后续业务不得虚构已支付、已承保或已提交。静态截图可作为视觉演示，但不能宣称截图中的输入、下拉、勾选已可操作；用户要求可填写时使用真实控件并验证。
- 使用一个明确的手机视口和内容滚动区；导航、正文、底部操作、弹层有明确归属。别让外层文档、iframe、手机壳、页面同时争抢滚动。
- 固定导航是同类页面共用契约，不是首页补丁。按已确认规则逐页固定状态栏/标题栏，并保留各页颜色；各页面颜色来自对应原稿，不把某一项目的品牌色或交付画板背景套到所有产品页。留足头部空间，不盖住首行。
- 返回、关闭、切换标签和打开弹层分别处理。标签只换对应内容，保留用户滚动位置；返回按来源恢复状态。不要调用整页重建或无条件 `scrollTo(0,0)` 来处理所有动作。
- 轮播/MOT 需跟手拖动、松手过渡、短拖回弹和首尾循环；拖动不误触 CTA，纵向滑动仍能滚页。内容长短不同时，保留各卡自然高度，容器、外层背景和后续模块同步平滑伸缩；只有原稿或用户明确要求等高时才统一高度，不能为了消除跳动给短卡留下大块空白。拖动中插值高度，松手后平滑归位；切换和首尾循环都不得突然裁切内容。统一管理自动播放的启动、暂停与销毁。
- 点击或拖动后出现多余边框，先区分真实 border、outline、box-shadow 与浏览器焦点样式。非选中态不因鼠标/触摸操作残留描边；键盘操作仍保留清晰的 focus-visible 提示，不全局关闭无障碍焦点。
- 从共用滚动层、导航组件、事件绑定和打包入口修根因。不要以遮挡、裁切正文、删除图片、任意缩字或硬编码某一手机高度掩盖问题。


## 交付外壳的分组选页菜单

继承已确认的意外险交付菜单结构：触发按钮 → 固定搜索区 → 独立滚动的分组列表。此规范只约束演示外壳，不改产品页面里的业务下拉框。

- 用项目已有业务模块或流程做分组标题，组内按页面职责和状态排列；只保留有实际内容的组。不要直接遍历所有导出帧生成平铺长列表，也不要照搬意外险的业务分类。
- 菜单项映射稳定页面 ID；一个页面只列一次。不同流程的同名页面通过分组上下文区分，不因名称相同就合并不同目标。完全相同目标的重复帧可用别名映射到同一项，深链仍保持兼容。
- 搜索匹配分组、页面名和状态；过滤时保留匹配项所属标题，隐藏空组，零结果给出明确提示。重新打开清空搜索。当前项用选中背景与勾选标记，页面跳转及深链恢复后同步。
- 搜索框不随长列表滚走；列表底部可达。方向键、Home/End 移动至可见选项，Enter 选择，Escape 关闭并回到触发按钮；点击外部关闭，选择后回焦点。长名称换行，窄屏不裁字、不出现横向溢出。
- 验收覆盖全部目录目标、同名不同组、搜索/零结果、当前项同步、底部滚动、键盘与关闭、窄屏和矮屏。保留既有业务跳转、返回与历史版本边界。
