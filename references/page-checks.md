# 每页检查，不按一次首页检查代替全流程

先列出实际路由/场景，不要求生成不存在的页面。工作记录可用：

| 页面/状态 | 真实入口与返回 | 首屏 | 上划后头部 | 页底/吸底 | 弹层/输入 | 目标内容 | 证据与边界 |
|---|---|---|---|---|---|---|---|

不适用项写 N/A，并说明简短原因；未测写未测。不要把这张内部检查表自动加到客户展示页里。

## 通用检查

- 对照原稿：标题、文案、列表项、图标比例/透明背景、状态、分组、间距、分割线、卡片圆角一致。图标不能被压扁、带非预期阴影或出现白方块；文字不因 `font-size:0`、mask 或父元素覆盖而消失。
- 首屏、滚动中、底部：固定头的视口坐标不变；背景不透明、颜色正确，正文不会从标题后透出。确认祖先的 overflow/transform/zoom 是否让 sticky 失效。状态栏和标题栏作为同一固定区域处理，不能只固定其中一个。
- 头部占位与原稿一致：新客与老客的顶部间距可能不同，抽公共导航时不能抹掉差异。
- 返回、关闭、浏览器/原型返回入口去正确来源，保留约定的标签、已填内容和滚动位置。不应意外回首页或留下遮罩、滚动锁和过期计时器。
- 同类页面复用修复；绝对定位页、普通文档流页、长截图页分别检查，不能假设同一条 CSS 对所有结构都生效。

## 页面类型

| 类型 | 必查行为 | 可测证据 |
|---|---|---|
| 首页/标签 | 默认推荐正确；切换仅替换列表；资产和待办不重建；固定标题色保留；同标签重复点击无跳动 | 切换前后 scrollTop 与标签视口位置；新/老客分别截图 |
| MOT/轮播 | 左右跟手、短拖回弹、完整翻页、首尾循环、自动/手动衔接；按钮可点；拖动后不触发按钮；纵向滚动正常 | 拖动中轨道位移和高度插值；长→短/短→长的卡片与背景高度；下方模块 y 的连续变化；首尾归位；实际触摸事件及操作后描边 |
| 保单/理赔记录/设置/对象列表 | 标题固定；最后一项可见；卡片与操作点去正确页面；无数据/短列表也不破坏导航 | 首屏与上划后标题 y；最后项可滚入；回到来源 |
| 商品卡/详情 | 正文与 View details 去详情；主 CTA 按确认的业务去投保；无动作入口不误触父卡跳转 | 从真实按钮触发并断言目的页标识，不只直接调用路由函数 |
| 长详情/信息确认 | 正文完整可读；导航固定；价格与主按钮吸底；最后一行/协议不被挡；返回可用 | 正文滚到底；头/底位置不变；静态图页检查裁切接缝和热区 |
| 半弹层 | 遮罩覆盖当前手机视口；底部对齐；内容超长内部滚动；关闭始终可达；背景不可点、不可滚；最后输入与按钮留足间距 | 矮屏及键盘状态；遮罩与设备边界；关闭后背景恢复 |
| 编辑/表单 | 输入内容可读；无额外框住文字的编辑边框；输入类型与错误提示合理；保存后列表更新；取消不误保存；键盘不挡住操作 | 实际输入、保存、重开；键盘 Tab 与 Escape；按钮焦点可见 |
| 图片承接页 | 不拉伸图片或图标；拆分头/体/底不重复不漏行；返回热区对齐；图内静态表单不冒充可编辑 | 顶部和底部截图；原始图片尺寸；功能边界说明 |

## 回归触发与边界

共用导航、滚动、缩放、弹层或打包逻辑变化时，重测所有受影响页面类型；单一路由修复时，重测该入口、目标、返回和共用组件的代表状态。交付前页面清单必须覆盖所有实际可达页面，不能用抽样替代初次全量核查。

尺寸取实际目标设备；未知时可用 375、390、430px 宽和一个较矮视口。有完整总览外壳/iframe 时在外壳里再测，避免外壳占用高度后露底或遮挡。

自动化至少结合截图复核；测量通过但图中标题/图标缺失仍然失败。截图通过也不代表拖动和入口可用。清楚区分桌面浏览器、手机模拟、真机和聊天软件附件内置浏览器。

## 内容高度不同的 MOT：专项验收

适用于本项目用户已确认的自然高度模式，也用于其他明确要求自适应内容的卡片轮播：

- 分别量出每张卡片的自然高度，不使用所有卡的最大高度统一撑开；flex 轨道不得把所有子卡默认 stretch 成等高。
- 切换到短卡，卡片底部只保留模板规定 padding，外层橙色背景同步变短；切到长卡平滑增高，文字和按钮均不被截断。
- 拖动中用横向进度插值当前与相邻卡高度；松手完成/取消时高度和位移用一致节奏到达目标。首尾克隆复位不能再次跳高。
- 验证动画开始、中间、结束三个时刻，不能只截结束态。高度变化应有中间值，下方模块随正常布局连续移动，不用整页 scrollTo 抵消跳动。
- 对指针拖动结束后的 focus/outline/border/box-shadow 单独检查；保留键盘可见焦点。不得用全局 outline:none 解决局部轮播描边。
- 字体加载、内容更新后重新测量；减少动态效果偏好下允许缩短动画，但最终高度与可达性必须正确。
