# 设计交付 Skill

用于 Figma 交付画板、离线 HTML 设计总览与交互原型。入口见 [SKILL.md](SKILL.md)。

## 安装

将仓库克隆到 `~/.codex/skills/offline-design-prototype-html`，或将完整文件夹放入所用代理的 skills 目录。

## 依赖与参考

- 产品 UI 工作依赖 `ui-quality-gates`。
- 汇报及设计策略文案引用同级安装的 `humanizer-zh`。
- Figma 操作需要对应 Figma 工具及技能。
- 文档中的 Figma 母版链接需要原文件访问权限；本地历史参考路径仅记录来源。

本仓库保留原 skill 及参考文件，不包含项目设计稿或交付 HTML。
